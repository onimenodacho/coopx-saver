1. Aceptación de estos términos

Estos Términos de servicio regulan el uso de la aplicación móvil CoopX Saver y de los servicios relacionados que ponemos a disposición de los usuarios.

Al instalar, acceder o utilizar CoopX Saver, aceptas estos Términos de servicio y nuestra Política de privacidad.

Si no estás de acuerdo con estos términos, no debes utilizar la aplicación.

2. Descripción del servicio

CoopX Saver proporciona herramientas que permiten al usuario introducir enlaces y solicitar el análisis y procesamiento de determinados contenidos disponibles en servicios de terceros.

Las funciones disponibles pueden incluir análisis de enlaces, selección de formatos, procesamiento de solicitudes de descarga, almacenamiento local de archivos, anuncios recompensados para determinadas funciones y otras funciones que puedan incorporarse a la aplicación.

Las funciones disponibles pueden cambiar, suspenderse o dejar de estar disponibles cuando sea necesario.

3. No se requiere una cuenta

La versión actual de CoopX Saver no requiere que el usuario cree una cuenta para utilizar sus funciones principales.

CoopX Saver no ofrece actualmente inicio de sesión ni autenticación mediante X y no solicita, recopila ni almacena contraseñas o credenciales de acceso de X.

4. Responsabilidad del usuario sobre el contenido

Tú eres responsable de los enlaces, archivos y contenidos que introduzcas o proceses mediante CoopX Saver.

Antes de descargar, copiar, almacenar, modificar o utilizar contenido de terceros, debes asegurarte de que tienes los derechos, permisos, autorizaciones o cualquier otra base legal necesaria para hacerlo.

No debes utilizar CoopX Saver para infringir derechos de autor, marcas, derechos de imagen, derechos de privacidad, derechos de propiedad intelectual u otros derechos de terceros.

CoopX Saver no concede al usuario derechos de propiedad intelectual sobre contenidos pertenecientes a terceros.

5. Uso permitido

Debes utilizar CoopX Saver de forma legal, responsable y de acuerdo con estos términos y con las leyes aplicables.

Está prohibido utilizar la aplicación para:

  • Infringir derechos de terceros.
  • Acceder sin autorización a cuentas, sistemas o servicios.
  • Eludir medidas de seguridad, restricciones de acceso o controles técnicos.
  • Interferir con el funcionamiento de CoopX Saver o de sus servidores.
  • Realizar actividades fraudulentas, abusivas o ilegales.
  • Distribuir malware, código malicioso o contenido diseñado para perjudicar sistemas.
  • Realizar solicitudes automatizadas que puedan degradar o sobrecargar nuestros servicios.
  • Utilizar el servicio de manera que incumpla las condiciones de un servicio de terceros.

6. X y otros servicios de terceros

CoopX Saver puede procesar enlaces asociados con X (anteriormente Twitter) cuando el usuario proporciona dichos enlaces voluntariamente.

CoopX Saver no es X, no representa a X y no está afiliada, patrocinada ni respaldada por X, salvo que se indique expresamente lo contrario.

El uso de X y de cualquier otro servicio de terceros está sujeto a los términos, políticas y restricciones de dichos servicios.

El usuario es responsable de cumplir las condiciones aplicables a los servicios de terceros que utilice.

7. Servicios de terceros e infraestructura

CoopX Saver puede depender de servicios proporcionados por terceros, incluyendo infraestructura de servidores, alojamiento, procesamiento técnico y servicios publicitarios.

También puede interactuar con servicios externos cuando el usuario solicita funciones que dependen de ellos.

Los servicios de terceros pueden estar sujetos a sus propios términos, políticas de privacidad, restricciones técnicas y requisitos de uso.

La disponibilidad o funcionamiento de una función puede depender de cambios realizados por dichos terceros.

8. Publicidad

CoopX Saver utiliza Google AdMob para mostrar publicidad.

Algunos anuncios pueden ser anuncios recompensados que el usuario elige voluntariamente ver a cambio de un beneficio dentro de la aplicación.

En la versión actual, la visualización de un anuncio recompensado puede utilizarse para desbloquear la descarga en calidad HD cuando dicha función esté disponible.

La publicidad, la segmentación, la medición y las opciones de consentimiento pueden depender de la configuración de privacidad del usuario y de las tecnologías proporcionadas por Google.

Para obtener información sobre el tratamiento de datos relacionado con publicidad, consulta nuestra Política de privacidad.

9. Consentimiento y privacidad

El tratamiento de información personal relacionada con CoopX Saver se describe en nuestra Política de privacidad.

Cuando la legislación aplicable exija consentimiento para determinadas finalidades publicitarias o de privacidad, CoopX Saver utilizará los mecanismos de consentimiento correspondientes.

Cuando la aplicación muestre una opción de preferencias de privacidad, el usuario podrá utilizarla para revisar o modificar las opciones disponibles de acuerdo con la legislación aplicable.

10. Portapapeles

CoopX Saver no realiza un monitoreo continuo del portapapeles.

La aplicación puede acceder al contenido del portapapeles cuando el usuario utiliza expresamente la función Pegar para introducir un enlace.

11. Descargas y almacenamiento local

Los archivos procesados o descargados mediante CoopX Saver pueden almacenarse localmente en el dispositivo del usuario de acuerdo con las funciones disponibles en Android.

El usuario es responsable de administrar los archivos descargados y de asegurarse de que su almacenamiento y utilización sean legales.

Las funciones de la aplicación pueden permitir eliminar archivos descargados o datos locales. El usuario también puede administrar o eliminar los datos de la aplicación mediante las opciones proporcionadas por Android.

Intentamos mantener CoopX Saver disponible y funcional, pero no garantizamos que el servicio esté disponible de forma continua, ininterrumpida o libre de errores.

El funcionamiento de determinadas funciones puede depender de servicios externos, redes, servidores, cambios técnicos, mantenimiento o restricciones impuestas por terceros.

Podemos realizar mantenimiento, modificaciones, actualizaciones o interrupciones temporales cuando sea necesario.
